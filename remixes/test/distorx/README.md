# `distorx` — DISTORX alone

DISTORX on FX1 and FX2 in SPATIALIZER's row (its id, `replaces=`), beside
the stock effects. Its 1,586 words (code and
table) need one run that long: CHORUS + PLATE REV + SPRING REV give theirs
(1,743 words up to the SPRING REV words DARK REV still calls), so DARK REV
stays (`modules/distorx/README.md` "Where it goes").

`make check REMIX=distorx`.

**Hardware:** the owner's MKI, image DTXPR3 (BUILD 96, on `0x05`), 22 Oct 2026, and before
it DTXPR1 (BUILD 91, on `0x0a`), 21 Oct 2026 (module README "On the unit").
