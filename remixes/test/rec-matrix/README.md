# `rec-matrix` -- REC MATRIX

One ColdFire module by Bryan Tysinger and the stock effects.

## What is in it

- **REC MATRIX** -- [`modules/rec-matrix/README.md`](../../../modules/rec-matrix/README.md).
- the 14 stock FX2 effects, listed so the chooser is stock's.

## Status

REC MATRIX ran on Bryan T's MKII in test builds with other modules (Oct-Nov 2026). This remix as a whole has not been flashed.

## Build

```bash
make image REMIX=rec-matrix BUILD=1
```

[BUILDING.md](../../../docs/guide/BUILDING.md) is the walk-through from a fresh machine to a flashed unit. `make check REMIX=rec-matrix` runs every gate first.
