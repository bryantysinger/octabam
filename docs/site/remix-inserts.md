# Octabam Inserts

![Spectrum, one of the insert effects](img/spectrum/main.png)

*Spectrum, one of the insert effects*

Octabam Inserts adds the core features and seven effects to Octatrack OS
1.40C. Each effect is an insert on its own track, on FX1, FX2 or both, and
the stock DELAY stays.

## The effects

Every effect below is an insert: it runs on any track, on the menus marked.
The stock DELAY stays; the other stock effects give up their DSP words.

There is no SIDECHAIN_COMPRESSOR: it overlaps CHARACTER's own compressor, so
stock COMPRESSOR keeps its id, undisturbed, with no side-chain KEY.

| Effect | FX1 | FX2 | Description |
|---|---|---|---|
| [SPECTRUM](reference/modules/spectrum.md) | ✓ | ✓ | filter: Moog ladder, SEM, Capacitor2, formants |
| [CHARACTER](reference/modules/character.md) | ✓ | ✓ | fold, saturation, tilt, compressor, width |
| [MODULATION](reference/modules/modulation.md) | ✓ | ✓ | Juno, Dimension, flanger, phaser, comb |
| [TRANSIENT](reference/modules/transient.md) | ✓ | ✓ | transient shaper (Ignorato) |
| [EUCLID](reference/modules/euclid.md) | ✓ | ✓ | Euclidean filter / amp sequencer (repeat98) |
| [DELAY](reference/modules/delay.md) | — | ✓ | Stock delay. |
| [GATE VERB](reference/modules/gateverb.md) | — | ✓ | Gated plate reverb with AMNT, GAIN, TIME, DIFF, TONE, and GATE controls. |
| [LOFI2](reference/modules/lofi2.md) | — | ✓ | Ring modulation or stereo frequency shifting, followed by sample-rate and bit reduction. |

The three stations are FX1-only in the bus remix; here each has its SLOTS
build setting at FX1+FX2, so an FX2 instance runs live. LOFI2 runs on FX2
only: it needs more DSP than the FX1 slots leave. CHARACTER's KEY = T1
needs a BusDelay host, so in this remix it keys on the track's own input. The
FX1 chooser lists NONE and the effects marked FX1; the FX2 chooser lists the
effects marked FX2. A MODE turned on the panel re-defaults the knobs around
it (the MODE DEFAULTS module).

## Build and install

1. **Back up the card.** KITS writes `kits.work` into each project it loads.
2. [Build and Install](web-builder.md) patches your copy of OS 1.40C into this
   remix in the browser and gives you the files to install.
3. **Old projects.** For a project made before this remix, on the card:

   ```bash
   python3 tools/hw/ot_project.py stamp-defaults "<card>/<set>/<project>" octabam-inserts
   ```

   A project made on the unit after the flash needs no stamp.
4. Follow [Install the image](web-builder.md#install-the-image) and confirm
   that SYSTEM STATUS → OS VERSION shows `OCTABAM` and the build tag.
5. To restore stock OS, follow [Safety and recovery](safety.md).

If the unit misbehaves, the failure register lists what has gone wrong and
why: https://github.com/sambanks/octabam/blob/main/docs/contributing/FAILURE_MODES.md

## Where it has run

Cursory testing on an MKII (owner report, 16 Oct 2026). Port gates:
`make check REMIX=octabam-inserts` and the reach round. MUTE_MODES from DRAM,
BRAIN and CC MAP's regenerated bytes have not run on a unit.
