Two pedals in one insert: the **BOSS SD-1** Super OverDrive and the **Pro Co
RAT**, with the Turbo RAT as a third mode, each modelled from its part
values. MODE picks the pedal; changing it fades to the dry signal and back in
about 3 ms, so a scene or a p-lock can switch pedals without a click. Built
for a TB-303 line, fine on anything.

## Access

An effect on a track: select the track, press FX1 or FX2, and pick DISTORX
from the chooser.

## Operation

MODE starts at **OFF**: nothing runs and the audio passes untouched, so
DISTORX can go on a track in the middle of a set. Turn MODE to SD-1, RAT or
TURB to fade a pedal in. IN sets how hard the track hits the pedal, DRIV the
pedal's own gain, TONE its tone (right is bright in every mode), LEVL the
level after it. MIX 0 is an exact passthrough.

## Parameters

| Knob | Default | What it does |
|---|---|---|
| LEVL | 64 | output level; 64 ≈ the input's loudness at DRIV 64, in every MODE |
| TONE | 64 | SD-1 TONE / RAT FILTER: 0 dark, 127 bright |
| DRIV | 64 | SD-1 DRIVE (18–47 dB) / RAT DISTORTION (0–67 dB) |
| IN | 0 | input gain into the pedal, −12 … +12 dB |
| MIX | 127 | dry/wet; 127 the pedal alone, 0 exact passthrough |
| MODE | OFF | OFF, SD-1, RAT, TURB (the Turbo RAT's red LEDs) |
