A crush insert: drive into a wavefolder, hard or soft clip, combined
bit-depth and sample-rate crush, then a feedback loop with a tone shelf.
MODE CHAOS flips feedback polarity from a free-running ramp. MIX 0 is
exact dry.

## Access

An effect on a track: select the track, press FX2 (or FX1 in remixes that
list it there), and pick Shatter from the chooser.

## Operation

Start with MIX up and everything else at 0 — dry. Raise DRV for input
gain into the folder, FOLD for wavefolding, CLIP for the brick, CRSH for
bit/SRR grit. FDBK recirculates the crush path; TONE shelves that loop.
MODE CHAOS flips FDBK polarity at a rate set by RATE.

## Parameters

| Knob | Default | What it does |
|---|---|---|
| DRV | 0 | pre-gain on dry only (~×9 at 127); 0 is unity. At 127 it clips ordinary input levels (~35% of samples at the rail on a 0.25 FS tone) |
| FOLD | 0 | wavefolder; 0 skips; 1…127 only increases fold |
| CLIP | 0 | clip threshold (0 open, 127 brick wall). Leave open to hear MODE/TONE/RATE clearly |
| CRSH | 0 | combined bit-depth and sample-rate crush |
| FDBK | 0 | feedback around fold/clip/crush (needed for TONE/RATE/CHAOS) |
| MIX | 127 | dry/wet; 0 is exact passthrough |
| MODE | HARD | HARD / SOFT / CHAOS (CHAOS flips FDBK polarity) |
| TONE | 64 | feedback shelf: 0 dark, 127 bright |
| RATE | 64 | CHAOS polarity flip rate; ignored in HARD/SOFT |
