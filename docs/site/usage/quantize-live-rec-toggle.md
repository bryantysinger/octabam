Toggles QUANTIZE LIVE REC from the front panel, without the PERSONALIZE
menu.

## Operation

Hold [REC] and tap [PLAY]: the setting shows in a toast, LIVE REC:
QUANTIZED or LIVE REC: UNQUANTIZED. Tap [PLAY] again while the toast is up
to invert it. If PERSONALIZE is open, its QUANTIZE LIVE REC check mark
changes at the same moment. The first [REC] + [PLAY] still starts live
recording, as on stock.

A setting changed this way survives a power cycle.
