### 1.1 About CX Osc Core

Octabam CX Osc Core is Octatrack OS 1.40C with the core features of
[Octabam](../octabam/index.md) and one new machine, **CX OSC**. All 14
stock effects stay, and no effect is added or replaced.

CX OSC is a complex oscillator in the Buchla manner: two-operator FM with a
sine wavefolder, fold symmetry and modulator feedback. It sits in the
machine list after the stock five.

### 1.2 What changes on the unit

- **CX OSC.** Choose it from the machine list on a track. Its playback
  page has PTCH, RATO, INDX, FOLD, SYMM and FDBK. It is mono and uses the
  stock LFOs. See [Cx Osc](machines.md).
- **The core features.** BRAIN, Kits, page 2 locks and scene locks, MIDI
  scenes, CC mapping, USB and the sequencer, recorder and card fixes are
  as described in the chapters of this manual.
- **No bus.** There is no delay and reverb bus and no SEND.

### 1.3 Before you install

Back up the CF card first. KITS writes a file into each project it loads.
A project made on the unit after installing needs no preparation; a project
made before needs it once, as described in
[Build and Install](../../../web-builder.md). To return to stock OS, follow
[Safety and Recovery](../../../safety.md).
